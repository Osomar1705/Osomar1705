## 👋 About me

> **EN** — I'm **Osmar Vilchez Aguirre**, a Computer Science undergrad at **UTEC (Universidad de Ingeniería y Tecnología, Lima – Perú)**. I build **full-stack products end to end**: typed React/Next.js front-ends, clean-architecture APIs in FastAPI and Spring Boot, and low-level C++ when the data structures have to be fast. I care about shipping — Docker, CI, and a real deploy URL at the end of every project.
>
> **ES** — Soy **Osmar Vilchez Aguirre**, estudiante de Ciencia de la Computación en **UTEC**. Construyo **productos full-stack de punta a punta**: front-ends tipados en React/Next.js, APIs con arquitectura limpia en FastAPI y Spring Boot, y C++ cuando las estructuras de datos tienen que volar. Me obsesiona que las cosas **lleguen a producción**, no que se queden en el localhost.
